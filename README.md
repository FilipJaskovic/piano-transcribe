## Piano Transcribe

Piano Transcribe is a work-in-progress app for turning piano recordings into something musicians can edit and use.

The first goal is to take audio of piano playing and transcribe the notes into a MIDI file. That should make it easier to capture an idea, clean up a performance, or move a recording into a DAW without replaying everything by hand.

Later down the road, the plan is to build on the MIDI transcription and generate readable sheet music too.
